# 返信テンプレ集

**目的**: 1案件あたりのメッセージ作業をコピペ3〜4回・5分以内に収める。

`【　】` の箇所だけ埋める。文章を考える時間をゼロにするのがこのファイルの役割。

> **注意**: ココナラのメッセージ自動送信は行わない。公開APIが無く、
> 自動化ツールでのアクセスは規約違反にあたる。アカウント凍結は収益源の消滅と同義。
> あくまで「手で送るが、文章は考えない」という形にする。

## ⑦ お断り（ログインが必要なサイト）

```
お問い合わせありがとうございます。

恐れ入りますが、ログインが必要なサイトからの自動的なデータ取得は、
多くの場合サイトの利用規約で禁止されており、
お客様のアカウントが停止されるリスクがございます。

そのため、当方ではお受けしておりません。

もし対象サイトが公式のAPIやデータ提供機能をご用意している場合は、
そちらを利用する形で対応可能ですので、お気軽にご相談ください。
```

> 断れることが信用になる。無理に受けて後で炎上するほうが損失が大きい。
